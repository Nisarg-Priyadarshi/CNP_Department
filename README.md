# CNP_Department
First project of an AWT subject. 

This project is basically a website that lets a person (Verified) handle Student Managed Clubs or GUIITAR Projects or gain information about them or apply for them (As per their clearance level). Basically, it _should_ be considered as the one, single platform for students, teachers or even higher ranking officials such as a Dean to access the data on SMCs or GUIITAR Projects by students.
